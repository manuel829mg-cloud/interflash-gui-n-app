# Inter Flash TV — Android TV / Fire TV (prototipo)

Proyecto Android nativo para Android TV y Fire TV. Incluye entrada Leanback y base Media3/ExoPlayer HLS.

**No es una APK terminada ni una aplicación de producción.** Falta autenticación de dispositivos, catálogo autorizado para clientes, control real de suscripciones en reproducción, pruebas de navegación con mando y compilación firmada. No contiene canales ni enlaces de retransmisión.

Abrir la carpeta en Android Studio (JDK 17), sincronizar Gradle y compilar un APK de pruebas. No distribuir ni cobrar hasta disponer de licencias de contenido y validar la seguridad.
